Блок 3. RAG и Vector Databases
Приоритет №1
RAG — Retrieval-Augmented Generation.

Это архитектура, позволяющая AI работать с внешними знаниями: документами компании, PDF, базами данных, инструкциями и другими источниками.

Технологии:
Технология	Для чего
LangChain	Интеграция LLM и компонентов AI
LlamaIndex	Работа с документами и данными
LangGraph	Сложные AI workflow и агенты
Qdrant	Vector Database
pgvector	Векторный поиск в PostgreSQL
Pinecone	Managed Vector Database
Weaviate	Vector Database
Elasticsearch	Полнотекстовый и гибридный поиск
FAISS	Локальный векторный поиск

Что нужно понимать:
1. Document ingestion.
2. Text chunking.
3. Embeddings generation.
4. Vector similarity search.
5. Metadata filtering.
6. Hybrid search (BM25 + Vector Search).
7. Reranking.
8. Context retrieval.
9. Retrieval evaluation.
Мой совет: начни с Qdrant + LangChain + OpenAI Embeddings, а затем изучи pgvector и LlamaIndex.

Не нужно одновременно осваивать все Vector Databases.
